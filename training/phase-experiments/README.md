# Mineral-phase experiments
Two private Kaggle experiments are running: extended-dice and small-grain-dice.
Each uses CE+Dice, seed42, 24 epochs x192 training patches, the frozen31/6 split, full native validation, and no held-out test evaluation. The second changes only training crop context: 50%256px crops resized to512, nearest-neighbour labels. It is an experimental scale augmentation, not super-resolution or guaranteed rare-phase improvement. The deployed model remains unchanged.
Generator runs from Desktop REEFPRINT training/prepare_extended_phase_experiments.py. In this application checkout copy the generator to training/ or adjust its ROOT to this checkout before running; base notebook is training/matched_ce_control_20260930/matched_ce_control.ipynb. Prepared notebooks/protocols are complete, source-hash bound and contain no raw data or credentials.
Do not claim improved test accuracy. Check Kaggle logs/results, compare per-phase native-validation IoU/recall and errors, repeat successful candidates on more seeds, and gate final model evaluation/approval separately. A larger run is not evidence of better results.
Scanning UI: actual backend stage/field callbacks, elapsed wall time; decorative scan line is labelled illustrative. CSS reduced-motion stops the scan. Screenshots in Desktop handover are mocked UI test fixtures, not real mineral predictions.
