# Optional language models for the REEFPRINT evidence assistant

Research started 30 September 2026; handover completed 1 October 2026 (South Africa). Recommendations below are candidates for evaluation, not claims of mineralogical accuracy. No provider credentials, model downloads or paid requests were used.

Keep the deterministic local evidence helper available. A language model can explain checkpoint-linked scores, rewrite a user-supplied observation, or suggest an approved workspace task. DeepLabV3 performs phase segmentation. An LLM cannot validate a phase, turn XRF elements into mineral truth, establish recovery gains, or bypass the simulator's gates.

## Integration details that matter

Featherless Qwen3 defaults to thinking mode. For short answers, send `chat_template_kwargs: {"enable_thinking": false}` as documented by [Featherless](https://featherless.ai/docs/chat-template-kwargs). The current 800-token / 35-second request budget must be tested against final text, not assumed sufficient for a reasoning model. The baseline adapter does not automatically set this flag. Ollama's equivalent needs its own compatibility test; do not assume Featherless kwargs work there.

Hosted providers need `REEFPRINT_ASSISTANT_API_KEY` **on the server only**. Leave the base URL unset so the fixed provider allowlist selects it. Ollama uses the existing `http://127.0.0.1:11434/v1` destination and does not require a paid key for local inference. Configuration alone does not prove a model is installed or ready.

Hugging Face is another routing option: `REEFPRINT_ASSISTANT_PROVIDER=huggingface`, base URL selected by the adapter, and an eligible Hub model ID such as `Qwen/Qwen3-8B`. A [Hub model card](https://huggingface.co/Qwen/Qwen3-8B) does **not** guarantee hosted availability. Confirm a live chat-completion provider mapping first, then test the account token. [Official chat-completion guide](https://huggingface.co/docs/inference-providers/en/tasks/chat-completion). Hosted free credits are limited; do not promise an unlimited free backend. [HF pricing and billing](https://huggingface.co/docs/inference-providers/en/pricing).

The Featherless public detail response quoted USD $0.117 per million input tokens and $0.455 per million output tokens at inspection. Plans, concurrency, quotas and prices can change; inspect account billing before enabling requests. AIMLAPI pricing was not verified. Local operation has no per-request provider charge but consumes the computer's resources.

Before recommending a winner, compare the candidates on the same small, recorded set of questions: correct score/source citation; confidence versus accuracy; sampled versus whole-image area; magnetite's zero-IoU limitation; no invented grade/recovery; draft-note approval; and refusing unsupported commands. Record latency, token usage and unsupported claims. None has been evaluated as a mineral expert here. Saved notes, coordinates, images and audio remain outside the current provider payload; the question itself is shared only after opt-in. Current note actions append an editable draft, not an automatic save.
