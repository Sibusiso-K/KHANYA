# UI audit and direction

## Verified failures
localhost:8501 showed render() unexpected keyword sample_title after Run held-out example. Upload/developer controls preceded the image workflow. Streamlit and fixed-height iframe rendered as separate shells. No coherent multi-screen navigation or shared specimen selection existed.

## Direction contract
THESIS: one selected specimen follows imagery, evidence and explicit simulation.
OWN-WORLD: user's approved white mockup, slate text, blue actions and fixed mineral hues.
STORY: select, analyse, inspect original/overlay/mask, review checkpoint-matched report, test simulated action.
FIRST VIEWPORT: sample library left, large image stage centre, phase panel right. Evidence and process sequence follow below. Visible primary Run analysis action.
FORM: user-selected scientific workbench, no random visual direction needed. Code-led functional adaptation of the approved composition.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
