## Review position posted to GitHub

1. **Outcome claims:** stage can claim labelled S2 phase identification with the explicitly identified held-out report and a simulator-only advisory-to-parameter path. It cannot claim less reagent, more recovery or faster sample-to-answer. The shadow pilot should define its measures; the 8–12 week duration is a planning estimate dependent on partner access and laboratory turnaround, not a commitment. Measure specimen-level expert agreement, coverage/abstention, unsafe-advisory count, repeatability and paired sample-to-reviewed-result turnaround. Keep reagent and recovery analysis exploratory during no-command shadow mode.
2. **South African domain:** the primary ask should be a partner lab supplying representative labelled South African polished sections, expert phase labels, specimen identity and acquisition metadata, with the evaluation split grouped by specimen. Unlabelled USGS imagery can support a qualitative stability/domain-shift check only if acquisition is comparable; it cannot support accuracy claims and should not delay submission.
3. **Initial customer and timing:** lead with a lab that already prepares and images the suitable sections, because this matches the model input. We have not shown that REEFPRINT removes an SEM/XRD queue, measured total turnaround or avoided sample preparation. No verified contact or turnaround figure is available. Measure a real workflow baseline in the shadow pilot.
4. **Decision-level performance:** report coverage, abstention, expert agreement and unsafe-advisory count with denominator alongside IoU. Zero observed unsafe advisories in 12 sections is not a zero risk rate and does not justify “never confidently wrong.” Define unsafe criteria and lock thresholds before evaluation. Fix all random seeds and run J0/J1/J2 after the submission freeze on training/validation only; do not tune on the 12 test sections. The one stochastic CE+Dice validation score does not replace the frozen stage checkpoint.
5. **Reflectance calibration:** the reflectance module exists, but is not ready to sit directly in front of the current KHANYA classifier in a pilot. It converts corrected camera counts to R% using a standard; the current model expects RGB images with its existing normalization. Calibrated inputs shift the model's input distribution, so the pipeline needs paired calibrated training/evaluation. A consistency gate is a reasonable future experiment with predefined perturbations on V1 and training/validation images only. For this submission, disclose lighting fragility rather than introducing an unvalidated gate.
