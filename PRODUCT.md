# REEFPRINT / KHANYA workbench

## Platform
Responsive React web frontend with a local FastAPI model service. Cloudflare/Supabase is the chosen deployment direction; this run first verifies localhost.

## Users and purpose
From the existing user brief: mineral researchers inspect reflected-light micrographs, identify phases, examine accuracy evidence, and demonstrate simulated plant parameter changes. Phone users capture records; desktop users inspect imagery and evidence.

## Constraints
The user approved the white three-panel mockup. Actual specimen imagery, checkpoint identity, and measured reports govern values. No invented assays, depth, grade, orebody or recovery gains. Field photographs are not the trained modality. Spatial image arrangement is illustrative until surveyed metadata is supplied. Simulation is an explicit user action. Records saved on-device are clearly labeled; no cloud sync claim.
